## 🎯 Nossa proposta

Propor soluções tecnológicas para os problemas dos nossos clientes, automatizando processos e tirando o trabalho repetitivo do caminho.

## 🧭 Onde queremos atuar

- 🌐 **Redes e infraestrutura:** monitoramento, disponibilidade e segurança
- 🤖 **Inteligência Artificial:** apoio à decisão e análise de dados
- ☁️ **Nuvem:** migração, deploy e operação
- ⚙️ **Automação de processos:** do levantamento do problema à entrega
- 💻 **Desenvolvimento de sistemas:** web, APIs e integrações

## 🚀 Projeto em destaque

**[SigmaTI](https://github.com/Solution-Explores/SigmaTI)**: monitoramento ativo de rede com apoio de IA e privacidade LGPD, desenvolvido como TCC para a equipe de TI de um hospital oncológico.
